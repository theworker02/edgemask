# edgemask

Edge encode/decode helpers for mask payloads in pipelines.

**Site:** https://theworker02.github.io/edgemask/

## Install / run

```bash
git clone https://github.com/theworker02/edgemask.git
cd edgemask
node src/cli.js
node --test
```
